# Open Food Facts — Network Programming Project

## Objective
Compare Selenium, BeautifulSoup, and API-based
scraping techniques using Open Food Facts.

## Performance Metrics
- Execution time
- Bandwidth consumption
- HTTP request count
- Average latency
- Reliability
- Data completeness

## Dataset
- 200 food products for machine learning
- 40 fixed products for scraper benchmarking
- Categories: Cereals, Biscuits, Chocolates, Yogurts

## Machine Learning
K-Means clustering based on nutritional values.

## Technologies
Python, Selenium, BeautifulSoup, Requests,
Pandas, NumPy, Scikit-learn, Linux, Wireshark,
tcpdump, UFW.

## Team Responsibilities
Person 1: Selenium, BeautifulSoup, Networking
Person 2: API, Multithreading, Data Analysis, ML
